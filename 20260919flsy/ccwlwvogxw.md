# 35岁以上是不是就不建议生孩子了，妊娠风险是主要原因

> 更新时间：2026-09-19 (UTC+8)

随着二胎、三胎政策地相继放开，越来越多的家庭想要满足自己儿女双全的愿望，但是要知道女性是有生育年龄限制的，合适的年龄做合适的事，于是超过35岁还要不要生孩子成了另一大热议话题。对次话题，网友们各执一词，认为建议生的一方不必不建议生的人数少，一起来看看网友们的不同观点吧。

网上总有人说要在35岁以前生孩子，35岁以后就不建议生孩子了，因为超过35岁以后女性生育能力会逐渐降低，胎儿和孕妇面临的妊娠风险会更大，宝宝出现先天疾病的几率也会增加。虽然说最适合生育的年龄在25-30岁之间，但其实女性35岁以后如果月经周期正常，排卵正常，在医生评估后还能够生育的情况下也是可以生孩子的。

## 35岁以上还建不建议生孩子

建议生

- 1. 生理上，只要女性月经、输卵管和排卵期正常，即使超过35岁，也可以正常受孕；
- 2. 社会上，现代医疗技术的进步使得晚孕或高龄孕妇的妊娠和分娩风险得以降低，医生和专家也能提供更好的护理和支持；
- 3. 经济上，许多人在35岁左右事业和财务状况相对稳定，不用检查在外奔波，可以为孩子提供良好的成长环境和教育资源，陪伴孩子的时间也更多；
- 4. 心理上，35岁左右的父母更成熟、稳定和有经验，且大多数家庭已经育有一胎，能够更好地应对育儿挑战，更有耐心和智慧。

不建议生

- 随着年龄增大，身体器官可能会逐渐衰竭，处于高龄孕妇，怀孕以后风险性比较高，容易出现妊娠期高血压或者糖尿病；
- 超过35岁以后女性生育能力会逐渐降低，卵子的质量会下降，胎儿出现染色体异常的可能就会更高，导致胎儿发育畸形的可能也会更高；
- 妊娠反应的症状会加重，导致更加严重的恶心、干呕等，同时其他怀孕的症状也会比适龄期女性更严重；
- 女性超过35岁再生育，很容易导致自己身体受创，生产后得不到好的恢复，可能会留下严重的后遗症；
- 生完孩子后，照顾小婴儿会让高龄妈妈心力交瘁，加速衰老。如果身体垮了，孩子得不到好的照顾，一家人的生活也会陷入混乱中；
- 当孩子二十正上大学的时候，父母的年纪已经五六十了。到了退休的年龄，很难再给孩子提供帮助。

需要注意的是，每个人的身体状况、生活环境和个人意愿都是不同的，所以对于是否在35岁生孩子这个问题，应该根据个体情况来综合考虑。如果计划在35岁之后生育，建议及时咨询医生，进行全面的身体检查和评估，以确保自身健康和宝宝的安全。
